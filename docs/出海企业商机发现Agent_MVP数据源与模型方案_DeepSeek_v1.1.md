## 1 当前选型

网页发现使用DeepSeek Search，LLM使用`deepseek-flash`。暂不使用SearXNG，不部署其容器，也不执行逐上游引擎验证。抖音仍是条件成立后才接入的可选渠道。

本方案替代旧数据源方案的SearXNG部分，并覆盖技术文档的供应商待选部分。沿用Python、FastAPI、单Worker、SQLite、原网页/官网核验、三表Excel、日报与500元月预算。任务ID保持稳定，详见[任务拆分](出海企业商机发现Agent_MVP开发任务拆分_v1.0.md)。

## 2 接口及凭据

| 用途 | 接入约定 |
| --- | --- |
| 搜索 | `POST https://api.deepseek.com/v1/tools/search`，JSON请求；`query`必填，使用`count`限制结果，默认`need_content=false` |
| 分析 | DeepSeek OpenAI兼容Chat Completions接口，模型名为`deepseek-flash`；结构化事实提取后仍由本地规则分级 |
| 凭据 | 统一从`DEEPSEEK_API_KEY`读取，通过Bearer鉴权；不写入TOML、SQLite、配置快照、日志、提示或报告 |
| 原文补全 | MVP保留HTTPX/HTML Fetcher及官网归属核验；DeepSeek Fetch可后续按需要启用，默认不新增第二条收费补全路径 |

密钥通过部署环境注入；仓库只提供空值[环境变量示例](../.env.example)，示例文件本身不会自动加载。用户已提供凭据，不在任务中再次索取；尚未验证其运行环境注入或账号权限。

官方依据：[网页搜索与抓取](https://api-docs.deepseek.com/zh-cn/guides/search/)、[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。实现前应再核对当时契约和价格，不能将选型确定等同于账号可用。

## 3 处理流程与缓存

配置校验→查询规划→预算预留→Search→结果缓存→允许范围内的原文获取→企业/地区归属→官网与商务入口→预算预留→deepseek-flash事实提取→引用校验→本地规则→Excel/日报。

- 搜索摘要仅用于发现，不能直接证明出海或支付需求。即使请求正文，正文缺失也不能用摘要补成事实；保留返回链接和字段来源。
- 搜索返回时间与原文核实时间分别保存；未知发布日期保持为空。排名与权威性信号不等于主体或产品适配成立。
- `search_cache`键含供应商、契约版本、查询及实际请求参数；不再含虚构的页码或本地引擎配置。失败不长期缓存，每次运行区分缓存命中、真实调用、空结果、故障与未运行。
- 原文仍执行域名、实际连接地址、重定向、限速、大小及内容类型检查。外部搜索接口地址固定，API调用者不能指定替代端点。
- 事实缓存继续包含企业、证据指纹、模型、提示与结构版本。配置记录请求模型及实际模型标识；供应商别名升级时保留版本信息并重新验证质量。
- 显式配置思考模式及输出上限；不要依赖供应商默认模式控制成本。模型不能执行网页中的操作指令或决定采集权限。

## 4 计费与故障

2026-10-24核对的参考价格：Search为5元/千次成功且有结果的请求；模型按token计费。Flash高峰价格为输入缓存未命中2元/百万token、输出8元/百万token。实际价格及适用条件以官方报价快照为准。

本项目实施约定：每次Search先预留0.005元；模型按高峰、缓存未命中价格及保守输入/输出上限预留。搜索、模型、其他收费数据服务共用500元月池，350/450元预警。Search与模型分别记cost_calls，不因共用账号混为一次费用。

明确空结果或已确认不计费的失败可结算为零；网络超时或断连而服务端结果未知时继续保留预留，不能据本地异常推断免费。每次收费重试重新预留。若以后启用DeepSeek Fetch，须独立计数、预留及核销。

401/402作为凭据或余额问题报告，不自动循环重试；429和临时服务错误有限退避。没有结果、没有权限、余额不足与服务故障分开统计。官方关于特定Agent工具暂未计费的说明不作为本项目直接API调用免费的依据。
